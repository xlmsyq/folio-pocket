# 随页 Folio

把 AI 生成的 Markdown、HTML 和纯文本，随时切换成适合手机的阅读版。支持连续阅读、按屏幕分页、HTML 静态原样预览和源码查看。

## 使用

1. 打开应用，选择「导入文件」或「粘贴内容」，也可以先打开示例。
2. 切换阅读 / 分页 / 原样 / 源码；用目录定位章节，搜索文中内容。
3. 在 Aa 中调整字号、浅色 / 暖纸 / 深色主题，或编辑更新内容。
4. 导出原文件、阅读版 HTML，或调用系统打印保存为 PDF。

PDF 导出依赖浏览器和系统打印能力，不是内置 PDF 转换引擎。分页模式按屏幕尺寸重排，导出的 PDF 使用独立的纸张排版，两者页码不保证相同。

## 功能与边界

- 中文界面，响应式布局，触控按钮，本地书架和阅读进度。
- Markdown 表格、列表、代码块；HTML 内嵌样式、内嵌光栅图片和静态 SVG。
- 单文件上限 2 MB；可一次导入多份文件。
- 文档在本机浏览器解析并存储到 IndexedDB，不上传文档内容，无账号、无分析追踪脚本。
- 首次在线加载并完成缓存后，可离线打开已缓存的应用；离线功能受浏览器存储策略影响。
- 支持 PWA 添加到主屏幕，具体入口取决于浏览器。
- 清除站点数据会删除书架。重要文件请保留原件或导出备份。
- 不执行导入文档的 JavaScript；不加载外部图片、字体或 CSS。外部链接仅展示地址，不自动打开。
- 交互式图表、Mermaid 和 LaTeX 不作专门渲染。
- 「原样」是经过内容过滤的静态预览，并非完整网页运行环境。
- 文件更新后需要重新导入或在应用中编辑；不会监视其他 App 或设备文件。

## 本地运行

应用没有构建步骤或运行时服务器依赖。将 `dist/` 作为静态网站目录，以 HTTP 在本机预览，或部署到支持 HTTPS 的静态托管服务。不要直接双击 `index.html`，因为模块与样式加载需要 HTTP 环境。

例如本机安装 Python 后：

```sh
python3 -m http.server 8080 --directory dist
```

访问 `http://localhost:8080`。服务工作线程需要 HTTPS 或 localhost。

## 开发与测试

使用 Node.js 24：

```sh
npm ci
npm test
npm run check
```

测试覆盖格式识别、围栏处理、文件限制、分页数学、Markdown/HTML 转换、危险内容过滤、外部资源限制、文档完整性、导出和 IndexedDB 保存。

首次发布验证状态：19 项自动化测试通过，JavaScript 语法检查通过。自动化测试使用 jsdom，不代替浏览器排版测试。本次开发环境的浏览器预览无法启动，因此手机真实分页、PWA 安装、离线恢复和系统 PDF 打印尚未实机验收；此版本作为体验版发布。

建议手机验收：iOS Safari 和 Android Chrome 导入长中文文档 → 分页到末页 → 改字号与横竖屏 → 目录和搜索跳转 → 关闭重开恢复书架 → 打印预览检查末段与表格。

## 目录

```text
dist/           可直接部署的静态应用
  vendor/       随包提供的解析与过滤依赖及许可证
tests/          Node.js 自动化测试
.github/        GitHub Actions 测试工作流
```

内容使用 Marked 解析、DOMPurify 过滤，并在禁止脚本和联网的 sandbox iframe 中显示。应用界面与文档分隔，导出内容也带有限制性 CSP。

## 许可证

本项目采用 MIT 许可证。Marked 和 DOMPurify 的许可证位于 `dist/vendor/`。
